# Turnus — Turnusplanlegging & Analyse

En norsk verktøykasse for turnusplanlegging, simulering og compliance-sjekk.

## Hovedfunksjoner

- **Simulator** — Test ulike turnus-scenarier før de settes i produksjon
- **Historisk analyse** — Analyser tidligere turnus for belastningsmønstre
- **Vaktkode-konfigurasjon** — Tilpasselig for ulike institusjoner
- **AML/HTA-compliance** — Automatisk sjekk av arbeidsmiljølov og tariffavtaler

## Teknologi

- Python 3.12+
- Polars for datahåndtering
- Streamlit for UI
- FastAPI for API (valgfritt)

## Kom i gang

```bash
pip install -r requirements.txt
streamlit run app.py
```
